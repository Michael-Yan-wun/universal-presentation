## AI Universe 動態背景（先前版本，正式頁面已改用選定宇宙圖像）

- 以使用者的 AI Universe 2026 活動海報為構圖、深藍星空、地球大氣光與金色連線的參考。

- 地球在首頁較明亮；產品、城堡與案例章節會平滑降低背景亮度。
- 首頁依 2026-09-18 使用者最新「03 地球融合版」參考圖重建：實心金色「10」、較低的積木層高，置於右下方深色太空站平台。「0」依後續修正移除頂端單塊，兩側柱與完整四塊底座對齊。積木逐塊落下組裝，鏡頭保留緩慢擺動。
- `dist/anniversary.js` 管理金色材質及太空站模組。平台由有厚度的倒角金屬板構成，包含錯落外緣、接縫、螺栓、接觸陰影及即時倒影。倒影只在首頁可見時繪製，使用 1024px 反射貼圖與柔化取樣。
- 首頁地球調整為後方完整弧面，右上方為金色曙光；切換章節時平滑回到較暗的背景構圖。首頁構圖以桌面簡報為驗收尺寸。
- 首頁可長時間停留：進場約 5 秒後出現第一道流星，之後約每 12–21 秒以四條路徑輪流劃過右側天空。星點各自緩慢閃爍；平台每 28 秒流過一道柔和金光，指示燈、曙光與金色反光也有細微明暗變化。離開首頁會停止流星及平台效果，減少動態效果偏好下保持靜態。
- 背景不攔截滑鼠、觸控或鍵盤；分頁隱藏時暫停，尊重系統的減少動態效果偏好。

### 走過十年的動畫（2026-10-09）

時間軸上方加入 SVG 成長人物，年份放在走道下方，讓人物不穿過文字。2016 年由嬰兒四肢爬行開始，依使用者要求放慢成長：前兩個年份維持爬行，2017.6–2018.4 年間才平滑站起學步，2020 年仍是孩童，2022 年為少年，最後幾年成為大人。2021–2025 延續成長狀態，不重新變回嬰兒。嬰兒整體縮至前版的 56%，以腳底為中心逐年放大，並延後骨架與頭身比例的成長；起始約 21px、最終約 63px，身高差接近三倍。人物穿品牌橘上衣、帶微笑，後段步幅與步速增加、重心輕快彈跳；到 2025 年抬手揮動慶祝，帶出七道短暫金色星芒。

每一年短暫停留，依序點亮年份、節點和里程碑內容，留下交錯的淡金腳印與細光跡，腳印和地面光影配合身形成長。抵達時帶出星芒、年份光暈及節點柔光；人物保持向量銳利，僅地面光影柔化。前段約 11.35 秒，後段約 9.75 秒，初始爬行約五秒，保留嬰兒與學步階段的閱讀時間。結束保留完整內容和最後位置，不自動換段。

再次點擊目前的年份區間可重播；切換年份或離開章節立即取消舊動畫、觀察器和事件監聽。人物與節點共用同一個 requestAnimationFrame 時鐘，隱藏分頁暫停；手機直向版與減少動態效果模式直接顯示全部里程碑。行走裝飾對輔助技術隱藏，不產生逐幀朗讀。


## WinEdge 新品發表（2026-10-18）

`codex/winedge-launch` 將口頭轉折後的畫面直接帶到 WinEdge 新品。定位為「最貼近現場的 AI 平台」，主視覺在產品下方依序展開製造業、機台、Agent、儀表板與 Robot 五個現場應用節點；總覽標題呼應「貼近每個現場，組合各種 AI」。主視覺沿用品牌青綠，積木由有散熱鰭片、網路孔與 I/O 的通用 Edge 主機承載；背景以較深的舞台色降低干擾。沒有新增硬體型號或效能數字。

發表改成三段大主題：① 串接／流程／推論／節奏合成一幅現場 AI 工作流；② 看板設計與驗證維運合成設計到上線的畫面；③ Plugin 與 WinChat Agent 合成能力擴充到巡檢任務的畫面。八項功能保持獨立資料，最後才以便當圖完整展開。每段一次前進，沒有額外子步驟，避免重複講解。畫面採可讀的 DOM 文字、SVG 線條與 CSS 動畫，中央產品沿用 Three.js。每幕由講者手動推進；轉場期間鎖定前後步驟，換章節會取消未完成動畫。

第一段將相機入口加寬並提高卡片，分三行列出 IP Camera／RTSP、Web Camera／USB、Basler 工業相機。視覺推論用兩行呈現「VLM、物件偵測、分類、影像分割」，同步更新八項能力文案與講者筆記。

產品模型採特寫專用幾何細節：積木圓柱 96 段、加密倒角與機殼圓角，其餘章節沿用原本幾何。便當圖產品畫布以四倍寬高取樣後縮小呈現，新品主視覺維持 2–3 倍，受 GPU 紋理上限限制。`resize()` 使用 `clientWidth/clientHeight`，避免進場 transform 導致畫布解析度偏小，並在視窗尺寸與章節變更時更新像素密度。

能力動畫佔舞台約六成寬度，以獨立 SVG 圖形、陰影、金屬接點與光流表達串接關係。青綠、冷藍、紫、琥珀用來辨別不同能力；主標題與功能要點保持固定，循環動畫僅作用於圖解。移除第二排能力導覽，保留原簡報的底部控制。

總覽前加入獨立實際案例頁：瓶蓋檢測內嵌影片、智慧烤箱多點溫控、WinChat 知識問答。影片進場自動靜音循環、離場卸載；減少動畫設定時改為手動播放。來源與狀態承接既有 Pitch，不將舊案例描述為新品已部署實績。

最後使用 14 欄底層網格形成不對稱便當圖：WinEdge 主卡跨兩列，雙路推論用寬卡、通道用窄卡，底部看板／Plugin／Agent 與上方錯開欄線。Agent 跨七欄，與中央產品形成主次。加入霧白看板與淡紫 Plugin 材質，和深色能力卡形成明暗變化；每張卡有專屬微動畫、分批進場與一次柔光掠過。中央 3D 使用保留區域追蹤定位，縮放時仍留在主卡內。八項能力均保留；卡片是純展示的 article，沒有箭頭、hover 跳轉或回到前面頁面的按鈕。以桌面 1920 × 1080 為主要構圖，另調整 1280 × 720 的卡片行高與產品位置。此分支目前為本機預覽，尚未替換正式 Sites 網站。


## WinChat 多模態知識與協作（2026-10-18）

- 保留「生命體成長 → 三塊能力 → 產品誕生」的關係。開場用雙側腦輪廓、神經節點、緩慢訊號與三個實體積木呈現成熟中的企業大腦。
- RAG／Agent／SKILL 分別使用灰紫、柔紫與深紫能力積木；誕生產品使用同色系霧紫質感。只影響 WinChat 章節，不調整全站產品色表。
- 每段採左側大字與右側大型圖解；RAG 以文件圖解掃描、VLM／LLM 雙路理解及 Embedding 知識索引為主。Agent 以三步任務和彙整輸出呈現；SKILL 以工具包、權限與三種應用組合呈現。
- 客服維修、新人培訓、現場巡檢三種應用在 SKILL 與產品收尾都能看見。官方介面改成可放大視窗，避免壓縮在舞台角落；介面來源與示意內容分別註明。
- `winChatUI()` 以穩定的主題 key 更新內容，`selecting` → `focus` 不替換標題 DOM。原有 3D 進入與融合流程保留，融合前必須完成三段。離開章節即移除圖解，重新進入時重設。
- 支援 1920 × 1080 與 1280 × 720 桌面投影。WinChat 模型採 2–3 倍畫布取樣；動畫使用 SVG／CSS，文字維持 DOM，並尊重減少動態效果設定。
- 功能來源為 AIWin WinChat 產品頁，多模態 RAG 的 VLM 讀圖定位依使用者此次補充。文件、答案、圖表與任務為演講情境，未加入客戶成果或準確率聲明。


## WinChat 舞台擴充（手動揭曉 / 2026-10-18）

- 保留神經大腦與 RAG／Agent／SKILL 實體積木入口。主題內容改為全舞台：上方短標題，中間大型圖解／官網介面，下方主題動作。
- 18 個主題步驟以講者控制；同一個 scene 的 DOM 保持穩定，以 reveal 狀態揭曉內容。官方介面使用原圖、連續 CSS 平移與放大，刻意裁切到來源引用、搜尋設定、Copilot 與工具管理區域。
- 三種按壓動畫：大幅手冊掃圖並揭曉 VLM／LLM／Embedding；工作目標展開為任務與摘要；專業積木向 Agent 接合並亮起連線。三種應用成果也需再次按壓才揭曉。
- WinChat 誕生積木放大至專屬 2.05 倍，另有官方工作區收尾。內容不是自動循環播放的影片，10 分鐘以上的講述可依現場控制。
- 機制修改僅針對 chat：beat 細分、主題完成條件、返回與誕生後工作區。其他產品章節不引入這些步驟。WinChat 滾輪不推進，方向鍵、Page Up/Down 與空白鍵保留。
- `docs/WINCHAT-KEYNOTE.md` 提供約 12:35 的講述稿；秒數只是建議，不出現在觀眾畫面，也不控制動畫時間。

### WinChat：大腦先行，積木收尾

- 進場僅顯示企業大腦：分層輪廓、溝回陰影、神經訊號與輕微景深擺動；RAG／Agent／SKILL 是敘事能力，並非醫學腦區標示。
- 用全站上一步／下一步控制，大腦周圍能力標籤與左側列表為純展示。保留實際大腦 DOM 與當下姿態，依 SVG 座標朝記憶／思考／技能區域平移放大，約 2.2 秒後接完整舞台內容；跨主題先拉遠再深入下一區。移除短暫更換的中間標題及內頁動作按鈕，內容只在鏡頭移動末段淡入。離場清除鏡頭與舊內容，減少動態效果偏好直接切換。
- SKILL 以能力節點連向大腦，實體積木直到最後的產品揭曉才出現。
- 收尾先讓大腦聚光縮合，再由既有 Three.js 場景揭曉 WinChat；完成條件與手動 18 步節奏維持一致。

### WinChat：以 Agent 統籌資料流（2026-10-18）

後續依使用者修正，覆蓋前述 RAG／Agent／SKILL 並列的版本：Agent 是核心，依序介紹 RAG 知識、SKILL 工作方法與工具能力，再到應用成果。實際產品未實作 MCP 接口，因此不在畫面、流程或講述稿介紹該協定，也不把 SKILL 描述成協定。總覽大腦中央標示 Agent；周圍 RAG／SKILL／Work 為講述區域，Work 代表輸出的成果。

細節不重複大腦：獨立 VLM 趨勢圖理解、多模態索引、檢索與引用、SKILL 工具調用與結果回傳、工作方法與執行、摘要生成、Agent 協作關係、三條應用資料流。以 SVG 路徑、方向性光點與分批內容進場呈現處理順序；文字使用 DOM。每張主要官網介面圖只展示一次，不以連續重複放大填充步驟。能力使用灰紫／冰藍／青綠，Agent 使用柔金，保留深空背景。18 步、講者手動控制與完成條件維持。
