# AIWinOps 與 WinEdge 夥伴頁講述稿

## 開場後的敘事順序

公司介紹 → 公司沿革 → **智慧城堡** → 感知世界 → AIWinOps → NumOps → WinChat → 能力協作 → WinEdge 新品與夥伴邀請 → 組合實績 → 封底。

### 城堡：先把十年的成果放在觀眾面前（約 60–90 秒）

「這十年，每一個專案都留下了一塊能力。今天，這些積木已經能組成一座完整的智慧城堡。底下接住現場，中間學會判斷，上面讓知識與行動連在一起，長出不同領域的智慧。」

「但這座城堡不是一天蓋成的。如果把公司的成長想成一個生命，它先學會感知，再從一次次專案中學習，最後才懂得思考與行動。接下來，讓我們回到每一塊能力的起點。」

這裡只講完整能力架構；WinEdge 新品的整合、功能與合作邀請留在後段。城堡沒有跳頁或展開按鈕；下一步直達感知世界，返回則回到公司沿革的 2021–2025 段。

## AIWinOps：讓經驗變成可重複的學習能力

保留 VISION 立體字進場與五個案例積木逐一出場。每案先看大幅影片，再看「取像 → WinEdge-V／Edge 硬體 → 現場結果」。既有底部前後控制、方向鍵與 Page Up / Down 都能推進，不需要點畫面內的額外按鈕。

五案之後的產品段落約 4–5 分鐘，可按現場節奏調整：

| 步驟 | 畫面 | 講述重點 |
| --- | --- | --- |
| 1 | 五案素材 → 官方資料集工作區 | 就像生命體整理記憶，先把不同場域的經驗分專案、分資料集。 |
| 2 | 官方蝴蝶多邊形標註介面 | 選擇目標 → AI 輔助 → 確認修正。讓人的判斷成為可學習的標註。 |
| 3 | 四種任務 × 原始案例畫面 | Wafer Map 分類、瓶蓋偵測、齒列分割技術展示、網布正常樣本。說明同一份學習能力如何用在不同問題。 |
| 4 | 樣本 → 模型 → 驗證動畫 | 從已有樣本學習特徵，再面對不同的影像檢驗判斷。 |
| 5 | 官方模型分析曲線 | 看學習歷程、比較訓練與驗證、找到修正方向。曲線為官網示範資料，不是新增客戶成效。 |
| 6 | 官方驗證介面 | 回看判錯或漏判的樣本，修正資料與標註，再持續驗證。 |
| 7 | 模型部署與現場回饋 | WinEdge-V 搭載 Edge 硬體，讓模型接回現場；新的情境成為下一次學習材料。 |

七步完成後，全部專案積木一起旋轉收束，揭曉 AIWinOps。最後停在清晰的大型產品積木，下一步接 NumOps。返回會逐步回溯；從產品返回時，回到部署段落，不會突然跳回十年總覽。

案例與硬體素材來源見 [CREDITS](../dist/assets/aiwinops/CREDITS.md)。官方截圖與流程動畫用於產品講解，不是即時訓練或控制設備。

## WinEdge：一頁邀請，建議 90 秒

位置：新品主視覺 → 三段能力 → 實際案例 → 功能便當圖 → **產品 × 服務 × 夥伴** → 組合實績 → 封底。城堡已前移，不再回跳。

### 畫面主句

**好的 AI，來自產品與服務的相遇。**

- 產品：讓能力可以複製。
- 服務：讓價值真正落地。
- 中央 WinEdge：把共通能力，做成共同底座。
- 結尾：**與各位夥伴，一起把 AI 帶進每一個現場。**

### 台上講法

這十年，我們學到：只有產品，客戶未必能把它用進自己的現場；只有服務，每個專案又容易重新投入大量人力。

所以，我們把可重複的能力做成 WinEdge，把現場的差異交給懂產業、懂設備、懂客戶的專業夥伴。產品是共同的底座，服務讓它產生價值，夥伴讓這份價值走得更遠。

今天發表 WinEdge，也是在向在座各位發出邀請：我們提供持續演進的平台，與各位的領域知識、整合能力和服務經驗一起，把一個成功的現場，變成更多現場都能使用的 AI。

**下一個十年，讓我們一起把 AI 帶進每一個現場。**

### 呈現方式

同一頁維持完整內容，產品、服務與四種合作專業沿光流連到 WinEdge。中心平台有緩慢浮動，節點持續微亮；講者可停留任意時間。文字不會定時替換，也沒有額外 CTA 或按鈕。夥伴類別表示合作邀請方向，不代表已簽約名單。
