# NumOps 舞台講述稿

以產品展示為主，建議約 8 分 30 秒。時間是人工配速，不會自動翻頁。使用既有前後箭頭、方向鍵或 Page Up / Down；台上不顯示額外操作提示。

## 開場 / 30 秒

從感知到學習：前面我們學會接收現場資訊，現在要讓一次次量測留下規律。以數據光帶呈現累積與預測，帶出 AutoML 與專家系統。

## 1. 讀懂數據

### 1. 讓每個數字，回到它的現場。 / 35 秒

承接生命體的成長：我們已能接收影像與數據，現在開始從經驗找出規律。不同訊號先對應到設備、時間與工作目標。光流與表格為示意。

### 2. 準備好資料，學習才有起點。 / 40 秒

用放大的 NumOps 官方畫面說明資料來源、預處理方式與資料集。平台支援資料清理、轉換與特徵工程；不是在台上操作正式系統。

### 3. 一份數據，不只一種答案。 / 40 秒

以三個問題帶出能力：判斷狀態對應分類、異常偵測；預測變化對應回歸、時間序列；發現相似性對應分群。專家系統留到後面用不同畫面展示。圖形為能力示意，沒有客戶效能數據。

## 2. 學會預測

### 1. 把反覆嘗試，交給 AutoML。 / 45 秒

資料與預測目標送入 AutoML，候選模型分路訓練再匯回比較。這是建模流程動畫，不是即時訓練或速度保證；沒有捏造準確率。

### 2. 選擇目標，開始建立模型。 / 35 秒

展示官方建立模型畫面，指出分類、回歸、時序、異常與分群入口及 AutoML。只需掌握場域問題，也能以視覺介面建立模型。

### 3. 模型好不好，用結果說話。 / 45 秒

展示官方模型排行榜與評估入口。截圖數字是官網示範資料，不是本次客戶結果，不將指標泛化為效能承諾。依任務檢視測試集與評估指標。

### 4. 數據會學習，經驗也能留下。 / 40 秒

資料走模型訓練，老師傅經驗走規則庫。歷史資料不足時可先建立專家規則，不代表無資料就能訓練出有效機器學習模型。兩條路依場域組合使用。

## 3. 回到現場

### 1. 把製程經驗，變成控制依據。 / 40 秒

沿用使用者 Pitch v5 第 34 頁案例：27 個風門與 15 個溫度點，結合 NumOps 與 WinEdge-N。右側動畫呈現多點量測與調整流程，非即時控制或節能成效實測。

### 2. 當 AI，遇見水務專家。 / 45 秒

WaterOps 是與 GSD 基士德合作的智慧水務平台，結合水務領域知識與慧穩 AI 建模及落地經驗。以合作的數據 AutoML 平台介紹，不把它說成 NumOps 的改名或單方擁有。官網說明可輸入水質數據、訓練模型、模擬成效與納入環工專家知識。

### 3. 從水質數據，到現場決策。 / 45 秒

水質與流量送入 WaterOps，結合模型與專家知識，再透過 WinEdge-N 對接現場。公開合作資料提及智慧加藥與曝氣控制；本圖合併呈現可依場域配置的應用方向，不宣稱同一客戶同時具備所有配置。

### 4. 學到的規律，回到設備旁。 / 40 秒

完成訓練與驗證後依授權部署至 WinEdge-N；亦可透過 API 或批次預測使用。現場新資料供後續檢視與再訓練，沒有宣稱無人審核的自動重訓。下一步將這些能力融合，揭曉 NumOps。

## 揭曉 / 30 秒

資料、模型、專家經驗、驗證、領域合作與 Edge 部署一起旋轉收束，誕生 NumOps 積木。停留在產品主視覺：讓數據成為決策能力。下一步接 WinChat，從數據規律走向企業知識與行動。
