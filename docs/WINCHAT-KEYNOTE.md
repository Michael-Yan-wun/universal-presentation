# WinChat 舞台講述稿：Agent 統籌知識與工作能力

預覽：<http://127.0.0.1:8765/?v=winchat-pdf-1#chat>

建議約 **12 分 35 秒**，18 個主題步驟，加開場與產品收尾。每一幕可以停留，不會依時間自動翻頁。

## 角色與操作

Agent 是統籌者：理解目標、規劃、調用能力、整理並檢視結果。RAG 提供可查證的知識；SKILL 提供工作方法與工具能力。依任務組合，形成實際工作成果。不要把 RAG、SKILL 和 Agent 說成三個並列的大腦，也不要把 SKILL 說成通訊協定。

用左右方向鍵、Page Up/Down、空白鍵或底部前後按鈕。總覽和內頁沒有其他動作按鈕、操作教學或計時，WinChat 停用滾輪翻頁。大腦用於總覽、主題鏡頭與最後凝聚；細節用不同資料流、示意圖及官網畫面。進場約 2.2 秒，沒有短暫換字的過渡標題。

## 開場（0:30）

「前面，我們讓這個生命體學會感知，在一個個專案中累積經驗。接下來，它要能理解一份工作，找到知識，使用方法與工具，把結果整理出來。這個統籌角色，就是 Agent。」

指向中央 Agent，再指向 RAG 與 SKILL，最後指向工作成果。

## 1. RAG：給 Agent 找得到的依據（4:15）

### 1. 企業的知識，不只在文字裡。（35 秒）

先看文件與圖解。RAG 是 Agent 可使用的知識能力，不是另一個與 Agent 並列的大腦。

下一步：看圖像如何被理解。

### 2. PDF 裡的架構，也能讀懂。（40 秒）

以 PDF 中的系統架構圖為例：VLM 看懂方塊代表的元件、箭頭方向與上下層級，再結合頁面文字形成圖像描述。也可用流程圖與元件圖說明，並保留原圖、文件、頁碼與圖號。本頁為概念示意，不是模型實測。

下一步：建立多模態知識索引。

### 3. 讓圖文，進入同一份知識脈絡。（45 秒）

文字與圖像走各自理解路徑，內容整理後建立檢索表示。VLM 看圖，LLM 理解文字；Embedding 的具體輸入依產品實作，本圖不限定特定拓撲。

下一步：走進企業知識庫。

### 4. 把經驗，整理成企業知識。（35 秒）

大型官網知識庫介面。企業可按部門、產品與任務整理內容，讓前面積木的經驗有地方留下。

下一步：看 Agent 如何找回知識。

### 5. Agent 提問，RAG 找回依據。（35 秒）

問題帶出相關內容與來源，再回到 Agent 的上下文。Vector、Hybrid、GraphRAG 是可配置的檢索方式，不代表每次都同時使用。

下一步：查看官方問答介面。

### 6. 知識問答，帶著引用來源。（30 秒）

官方問答畫面，只看介面與引用機制，不逐條解說截圖中的法規內容。不是即時連線。

下一步：展開來源追溯。

### 7. 每一份回答，都能回到依據。（35 秒）

用追溯圖示意答案、引用片段與原文頁碼的連結。知識建立時讀圖，回答時保留證據脈絡。下一段介紹 Agent 如何取得現況。

下一步：讓 Agent 使用 SKILL 工作能力。

## 2. SKILL：有方法，也有工具（3:00）

### 1. SKILL，把專業做法留下來。（30 秒）

SKILL 是 Agent 可使用的工作能力。以巡檢摘要說明任務輸入、作業步驟、可使用的工具與輸出格式；不把它講成某種連接協定。

下一步：看 SKILL 如何使用工具。

### 2. Agent 調用 SKILL，使用現場能力。（40 秒）

Agent 依工作選擇 SKILL，由方法與工具組合取得資料、使用分析能力。圖中系統為應用示意，可用工具依實際部署配置。

下一步：讓工具結果回到 Agent。

### 3. 工具回傳結果，Agent 整理脈絡。（35 秒）

工具回傳運轉紀錄與分析，RAG 提供相關知識。結果回到 Agent 整理；請沿著資料流介紹，示意內容不是現場即時資料。

下一步：查看 WinChat 工具管理。

### 4. Agent 可用的工具，由企業管理。（40 秒）

官方工具管理介面，指出工具包、單項工具與啟用控制。SKILL 的工作方法與可用工具一起構成工作能力，這張截圖僅呈現既有工具管理功能。

下一步：讓 Agent 按工作方法執行。

### 5. 按工作方法，完成每一個步驟。（35 秒）

依次顯示讀方法、RAG 查規範、工具取紀錄、Agent 產出摘要。SKILL 說明怎麼做，工具負責取得資料或執行能力；Agent 統籌與檢視。

下一步：走進實際工作情境。

## 3. 應用：把能力組合成工作成果（3:40）

### 1. 把知識與能力，放進一份工作。（30 秒）

提出整理今日設備巡檢摘要的工作目標。Agent 使用 RAG 的知識與 SKILL 的方法及工具，最後產出可供人員使用的結果。

下一步：走進營運戰情室。

### 2. 讓現況，進入同一個工作視野。（40 秒）

展示官方戰情室的指標、趨勢、事件與 Copilot。數字來自官網展示，並非本場即時紀錄；下一頁用資料流說明如何形成摘要。

下一步：把狀況整理成巡檢摘要。

### 3. 從現場資料，到有依據的摘要。（35 秒）

工具取得的現場資料與 RAG 的 SOP 合流。Agent 依 SKILL 的方法整理觀察、依據、待確認事項，交回人員使用。

下一步：看 Agent 的完整協作關係。

### 4. Agent，讓知識與工作能力一起運作。（35 秒）

工作目標在上方，中央 Agent 統籌。左側 RAG 提供知識，右側 SKILL 提供工作方法與工具能力，結果從下方輸出。三者不是並列的大腦。

下一步：看三種企業應用。

### 5. 不同工作，組合不同的知識與工具。（35 秒）

三條資料流從問題開始：圖片查修、流程學習、現場巡檢。Agent 依工作使用相應 SKILL 與 RAG 知識，按下一步再揭曉成果。

下一步：展開三種工作成果。

### 6. 讓專業，變成每天能用的成果。（45 秒）

三條流程抵達圖文答覆、流程導讀、巡檢摘要。都是應用示意；最後把 Agent、知識與工作能力凝聚成 WinChat 積木。

下一步：凝聚為 WinChat。

## 凝聚與收尾（1:10）

大腦聚光凝結為 WinChat 積木，停留 30 秒：「Agent 結合 RAG 的知識與 SKILL 的工作能力，讓企業的經驗能在每天的工作中持續使用。」

下一步進入官方工作區，講述 40 秒，再接回「協作成形」的積木故事。
