# WinChat 舞台講述稿：Agent 統籌知識與工作能力

預覽：<http://127.0.0.1:8765/?v=keynote-flow-1#chat>

共 12 個內容步驟，加大腦開場與積木揭曉，建議約 10–12 分鐘。時間只供排練，每一幕等待講者推進。

## 角色與操作

Agent 是統籌者：理解目標、規劃、調用能力、整理並檢視結果。RAG 提供可查證的知識，SKILL 提供工作方法與工具能力。依任務組合形成成果；沒有 MCP 接口的宣稱。

用左右方向鍵、Page Up/Down、空白鍵或底部前後按鈕。首次從大腦深入內容約 1.35 秒；後續內容與跨主題直接沿資料流程平移，不再反覆拉遠大腦。只有回到總覽時使用反向鏡頭。每張主要官網介面只展示一次，回上一章會停在前一章產品揭曉。

## 開場（30 秒）

「前面，我們讓這個生命體學會感知，在一個個專案中累積經驗。接下來，它要能理解一份工作，找到知識，使用方法與工具，把結果整理出來。這個統籌角色，就是 Agent。」

指向中央 Agent，再指向 RAG 與 SKILL，最後指向工作成果。

## 1. RAG：企業的知識與依據

### 1. PDF 裡的架構，也能讀懂。（60 秒）

以 PDF 中的系統架構圖為例：VLM 看懂方塊代表的元件、箭頭方向與上下層級，再結合頁面文字形成圖像描述。也可用流程圖與元件圖說明，並保留原圖、文件、頁碼與圖號。本頁為概念示意，不是模型實測。

下一步：建立多模態知識索引。

### 2. 讓圖文，進入同一份知識脈絡。（60 秒）

文字與圖像走各自理解路徑，內容整理後建立檢索表示。VLM 看圖，LLM 理解文字；Embedding 的具體輸入依產品實作，本圖不限定特定拓撲。

下一步：走進企業知識庫。

### 3. 把經驗，整理成企業知識。（50 秒）

大型官網知識庫介面。企業可按部門、產品與任務整理內容，讓前面積木的經驗有地方留下。

下一步：看 Agent 如何找回知識。

### 4. Agent 提問，RAG 找回依據。（45 秒）

問題帶出相關內容與來源，再回到 Agent 的上下文。Vector、Hybrid、GraphRAG 是可配置的檢索方式，不代表每次都同時使用。

下一步：查看官方問答介面。

### 5. 知識問答，每份回答都有依據。（55 秒）

官方問答畫面，同頁說明回答、引用片段與原始文件的追溯，只看介面與引用機制，不逐條解說截圖中的法規內容。不是即時連線。

下一步：讓 Agent 使用 SKILL 工作能力。

## 2. SKILL：有方法，也有工具

### 1. SKILL，把專業做法留下來。（55 秒）

SKILL 是 Agent 可使用的工作能力。以現場巡檢摘要說明任務輸入、作業步驟、可使用的工具與輸出格式；不把它講成某種連接協定。

下一步：看 SKILL 如何使用工具。

### 2. Agent 調用 SKILL，使用現場能力。（60 秒）

Agent 依工作選擇 SKILL，由方法與工具組合取得資料、使用分析能力。圖中系統為應用示意，可用工具依實際部署配置。

下一步：查看 WinChat 工具管理。

### 3. Agent 可用的工具，由企業管理。（50 秒）

官方工具管理介面，指出工具包、單項工具與啟用控制。SKILL 的工作方法與可用工具一起構成工作能力，這張截圖僅呈現既有工具管理功能。

下一步：走進現場巡檢情境。

## 3. 展示：現場巡檢摘要與輸出

### 1. 把現場資訊，整理成巡檢摘要。（35 秒）

提出整理今日現場巡檢摘要的工作目標。Agent 使用 RAG 的知識與 SKILL 的方法及工具，最後產出現場巡檢摘要，可依場域需求串接 LINE、警示設備，或匯出報告。

下一步：走進營運戰情室。

### 2. 讓現況，進入同一個工作視野。（45 秒）

展示官方戰情室的指標、趨勢、事件與 Copilot。數字來自官網展示，並非本場即時紀錄；下一頁用資料流說明如何形成摘要。

下一步：把狀況整理成現場巡檢摘要。

### 3. 從現場資料，到有依據的摘要。（40 秒）

工具取得的現場資料與 RAG 的 SOP 合流。Agent 依 SKILL 的方法整理觀察、依據、待確認事項，交回人員使用。

下一步：讓現場巡檢摘要送到需要的地方。

### 4. 現場巡檢摘要，送到需要的地方。（40 秒）

現場巡檢摘要形成後，透過 SKILL 與已配置的工具選擇輸出：LINE 通知相關人員、依規則連動現場警示設備，或匯出留存報告。三條連線依序亮起，停留展示成果；下一步直接凝聚並揭曉 WinChat，不再重複架構總結或應用列表。本頁為串接概念示意，不會實際發送訊息或操作設備。

下一步：揭曉 WinChat。

## 凝聚與收尾（30 秒）

大腦與神經訊號凝聚為 WinChat 積木。停留：「Agent 結合 RAG 的知識與 SKILL 的工作能力，讓企業經驗能在每天的工作中持續使用。」下一步直接接協作成形，不再重複工作區總結。
