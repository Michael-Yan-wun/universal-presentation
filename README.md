# Universal Presentation · AIWin 10 週年

**From Edge to Agent — 十年經驗，積累成功。**

慧穩科技十週年活動使用的互動式 3D 演講網站。以「生命體的成長」串起感知、專案學習、知識與行動；以積木呈現產品能力，最後揭曉整合影像與數據、可模組化擴充的 **WinEdge**。

- [正式展示網站](https://winedge-anniversary-experience.yanwun1214.chatgpt.site/)
- 使用情境：桌面、16:9 投影、講者手動推進。
- 技術：原生 HTML / CSS / JavaScript、Three.js **0.180.0**、本機圖片與 H.264 MP4。
- 執行不需要 npm 安裝、編譯、API Key、資料庫或後端服務；所需的 Three.js 與展示素材皆已收錄。

本倉庫保存目前的 AIWin 演講版本。修改內容與動畫需編輯原始碼，目前沒有通用簡報編輯器或即時 AI 訓練功能。

## 快速啟動

需求：Git、Python 3，以及支援 WebGL 2 的桌面瀏覽器。

```sh
git clone https://github.com/Michael-Yan-wun/universal-presentation.git
cd universal-presentation
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

開啟 [http://127.0.0.1:8765/](http://127.0.0.1:8765/)。在終端按 `Ctrl+C` 停止伺服器。

請透過 HTTP 開啟；直接雙擊 `index.html` 的 `file://` 方式無法可靠載入 ES Modules 與素材。若 8765 已被使用，可改成 8766 等其他連接埠，並使用對應網址。

> **`dist/` 就是此專案的原始網站檔案，也同時是發布目錄。** 它不是自動生成的建置產物；修改後需要保留並提交。

| 操作 | 功能 |
| --- | --- |

### Vision 一輪的順序

1. 在 `#decade` 觀看落下組裝與機器人學習動畫，按「從影像專案開始學習」。
2. 鏡頭深入積木，停留於立體 **VISION** 字幕，再帶出五案（進場約 8.8 秒）。
3. 點選案例後，該積木移至前景（約 1.85 秒），開啟影片與右側解說。
4. 按「看看硬體如何接起來」，呈現相機 → WinEdge-V 邊緣設備 → 輸出。**完成硬體段落才計入已看過。**
5. 五案都完成後，按「把經驗化為訓練」，觀看機器人累積知識，以及整理、標註、訓練驗證三個重點。
6. 按「誕生 AIWinOps」，五案、底座與完整專案陣列一起旋轉融合（約 8.2 秒）；產品落下後停留，等待講者繼續。

影片預設靜音、循環播放，使用播放器控制暫停與拖曳；關閉即停止播放。若瀏覽器阻擋自動播放，使用畫面上的播放按鈕。轉場期間前後切換會暫時鎖定。WinEdge 發表也由講者手動推進，不會自動跳到下一章。

### WinChat：12 分鐘舞台版

預覽：[WinChat 章節](http://127.0.0.1:8765/?v=winchat-stage-1#chat)。本次只調整 WinChat，其他產品與 WinEdge 新品發表維持原樣。

講述節奏與逐段內容：[WinChat 舞台講述稿](docs/WINCHAT-KEYNOTE.md)。建議 **12 分 35 秒**，是人工講述配速，沒有自動翻頁計時。

- **開場：** 神經網路大腦與三塊能力積木，接續生命體的感知與學習。
- **RAG，7 個步驟：** 大幅圖文手冊 → 按壓 VLM 掃圖 → 圖文與 Embedding 合流 → 官方知識庫 → 搜尋模式 → 問答 → 引用來源鏡頭放大。
- **Agent，5 個步驟：** 工作目標 → 按壓拆解任務 → 彙整輸出 → 官方戰情室 → AI Copilot 聚焦。
- **Skill，6 個步驟：** 專業能力積木 → 按壓接合 → 官方工具管理 → 啟用區放大 → 客服維修／新人培訓／現場巡檢 → 按壓揭曉成果。
- **誕生，2 幕：** 三個主題完成後才融合，揭曉大型 WinChat 積木，再進入大幅官方工作區，最後接回協作成形。

右方向鍵、Page Down、空白鍵或主題動作按鈕推進；左方向鍵／Page Up 逐步返回。各步可停留，沒有時間到了就跳頁；WinChat 的滾輪翻頁停用，避免觸控板誤操作。直接從總覽選主題時仍須看完三個主題才能融合。標題不會在 3D 轉場完成時重新跳動；同一張官方介面的前後步使用連續平移放大。

官方知識庫、問答、戰情室、技能及工作區圖像都放在主要舞台，不依賴小預覽視窗。來源與檔案記錄見 [`assets/winchat/CREDITS.md`](dist/assets/winchat/CREDITS.md)。高解析度官網圖片保留原檔；CSS 鏡頭裁切與標示聚焦重要區域。所有產品介面為展示截圖，並非即時連線；VLM 圖解、Agent 任務及三種應用結果為演講示意。多模態 RAG 的 VLM 讀圖能力依使用者補充，其他功能參考 [AIWin 官方產品頁](https://www.aiwin.com.tw/products/winchat)。

實作分工：

- `winchat-script.js`：18 個手動步驟的文案、順序、講述秒數與隱藏提詞。
- `winchat-keynote.js` / `winchat-keynote.css`：大型官網畫面、點擊揭曉與攝影機聚焦效果。
- `winchat-story.js` / `winchat-story.css`：大腦總覽與原有三塊積木融合視覺。
- `product-journey.js`：WinChat 專屬逐步推進、返回與完成條件，NumOps 保留原流程。

驗證指令：`node --test tests/winchat-keynote.test.mjs`。涵蓋停留不自動推進、先完成所有主題、跳入 Skill、逐步返回、重入重設與 NumOps 原有路徑。桌面 1920 × 1080、1280 × 720 另以瀏覽器檢查。減少動態效果偏好會停用裝飾與轉場動畫，但保留手動揭曉內容。

### WinEdge 新品發表（`codex/winedge-launch`）

本分支在 GitHub 同步版本 `2689f37` 上開發。預覽入口：[WinEdge 新品](http://127.0.0.1:8765/?v=winedge-detail-1#winedge)。畫面已移除「One more thing」，轉折由講者口頭帶出；舊 `#one-more-thing` 連結仍會進入新品章節。這份分支內容尚未發布到正式 Sites 網站。

若從主分支取得此版本，先執行：

```sh
git fetch github
git switch codex/winedge-launch
```

若透過一般 `git clone` 取得倉庫，預設遠端名稱是 `origin`，請將上述 `github` 改成 `origin`。

新品主軸是 **「WinEdge，最貼近現場的 AI 平台。」** 依製造業、機台、Agent、儀表板與 Robot 等現場需求，組合影像、數據與 AI 能力。開場以五個應用節點接在實體 Edge 主機下方，總覽再次收束這個定位；這五項是應用方向，非新增五個已驗證客戶案例或 Robot 通訊規格。定位與節點由 `launchPositioning` 管理。

現場發表縮為 **三段主題**，不再逐一講八頁功能。原始提案中的即時預覽與熱更新仍合併為一項；完整八項能力保留在最後便當圖，三段主題剛好各涵蓋一次：

| 段落 | 演講主題 | 整合的能力 | 大動畫 |
| --- | --- | --- | --- |
| 01 | 接上現場，組合 AI | 工業串接、視覺化流程、雙路 AI 推論、通道與節奏 | 相機／設備／資料庫匯流，影像與數據雙路推論後輸出；底部以同步訊號呈現時序控制 |
| 02 | 設計到維運，一氣呵成 | 自由設計看板、即時驗證與維運 | 看板元件對齊組裝、設計／預覽／發布，接到單一模型節點暫停、熱更新與恢復 |
| 03 | 擴充能力，交給 Agent | Plugin 擴充、本地 AI Agent | 客製模型／產線邏輯／元件／整合向核心接合，WinChat RAG + Agent + Skill 連到巡檢任務 |

一段只需按一次前進，沒有隱藏的八個子步驟。精簡的是發表節奏，功能規劃不變：VLM、物件偵測、視覺分類／分割、數據分類／迴歸／時序、佇列與背壓、保完整／保最新、多來源時序對齊、全速／間隔／日週排程、圖層分組、對齊縮放、CSS 與素材客製等細節保留於八項資料、整合動畫或講者筆記。

第一段的「相機／串流」卡片分行列出 IP Camera／RTSP、Web Camera／USB、Basler 工業相機。視覺推論以 VLM、物件偵測、分類與影像分割呈現，總覽與講者筆記同步使用這組能力名稱。

順序為 **新品主視覺 → 三段主題 → 實際案例 → 八項能力便當圖 → 智慧城堡**。每一幕轉場結束後停留，場景內的資料光流等動畫持續運作。`→` / `←`、`PageDown` / `PageUp`、底部箭頭依序推進或返回；新品章節停用滾輪切幕，避免誤跳。已移除中間的能力導覽列，僅保留原本底部簡報控制。總覽為純展示：八張卡片不再是按鈕，沒有右上角箭頭，也不會跳回細節。重新進入新品章節會回到主視覺。

最後便當圖採不對稱拼接：大型 WinEdge 主卡跨兩列，右上為寬版雙路推論，右側穿插通道與維運小卡，底部看板、Plugin、寬版 Agent 的分欄錯開。青綠、藍紫與琥珀搭配兩張淺色卡片；八項能力各有 SVG 小動畫。卡片分批進場，WinEdge 積木與實體主機放大呈現。`wl-core-product` 預留產品空間，由 `fitProduct()` 依版面位置同步 WebGL 畫布，避免變更視窗尺寸後模型壓到標題；離開總覽即清除位置設定。

產品特寫使用較細緻的積木圓柱與機殼倒角。總覽的小型產品畫布按 CSS 尺寸的四倍寬、高繪製後縮小顯示，以改善邊緣鋸齒；新品主視覺採 2–3 倍，其餘章節維持最高 2 倍。解析度受 GPU 紋理上限約束，切換章節或調整視窗時會重新計算像素密度；尺寸使用未受進場變形影響的版面寬高，避免畫布放大後模糊。

場景採大幅圖解與固定左側文案，依能力使用青綠、藍、紫、琥珀等色彩，搭配高對比 DOM 文字與 SVG 圖形。資料沿線匯流、雙路模型、時序同步、單節點更新、看板元件對齊與模組接合整合為三幅主動畫；3D 積木由通用 Edge 主機承載，最後收束於彩色便當圖中央。硬體為概念模型，功能圖解與看板數字為示意，不是實際產品操作錄影或設備即時資料。功能名稱依使用者提供的新品提案，沒有額外加入硬體規格、效能或零停機保證。

### 常見修改

內容或動畫修改後，以本機 HTTP 預覽檢查：

- 桌面 1920 × 1080 下文字、積木、按鈕與頁尾無遮擋。
- 感知世界依序展開影像、數據，再進入十年學習。

- 瀏覽器主控台沒有模組或素材載入錯誤；系統開啟減少動態效果時仍可閱讀與推進。

本次 WinEdge 分支已以瀏覽器檢查 1920 × 1080 與 1280 × 720 的主視覺、三段整合主題、實際案例及八項總覽。已操作逐幕前進、返回、影片自動播放、離場卸載、轉場中切換章節及重新進入；確認中間導覽列、卡片按鈕與右上箭頭均已移除。檢查 JavaScript 語法、本機模組與媒體引用，以及案例／總覽步驟順序。檢查範圍為桌面預覽，不代表跨瀏覽器效能認證。

### 部署方式

任何可提供靜態檔案的 HTTP 主機都能使用 `dist/`，需完整保留相對目錄。章節採 URL hash，不需要伺服器端路由重寫。展示本身不呼叫外部 API；外部資料來源連結仍需網路。

目前正式版由 **Sites** 託管，`.openai/hosting.json` 指向既有 AIWin 網站，發布目錄是 `dist`。**推送 GitHub 本身不會更新正式網站。** 維護既有網站時沿用其設定；若要建立另一個網站，需使用新網站自己的識別設定。
